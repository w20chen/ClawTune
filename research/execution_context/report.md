# 最终执行上下文耗时修正

唯一评测入口：

```powershell
python -m offline.evaluate_execution_context
```

正式实现位于 `services/sidecar/src/execution_context/`。离线评测与 Sidecar 共用同一个模型：先按命令及历史上下文匹配耗时样本，再用至少 5 条、3 个任务且同类失败占比至少 98% 的训练组修正提前失败。证据不足保留原预测。查询返回同一批样本计算的均值、中位数、P90 和分桶概率；不执行探测命令。

模型文件为 `execution-context-kb.json`，公共格式由 `contracts/execution-context-kb.schema.json` 定义。Sidecar 自动加载 KB 目录中的该文件，并将新增有效观测按执行前快照学习和持久化。冻结模式仅更新会话历史，不学习测试耗时。结果输出在 `results.json`，逐条预测在 `predictions.json.gz`。

固定任务划分：训练 5,268 条，开发 427 条，测试 848 条 shell。644 个源文件校验通过并保持只读。测试集曾被审查，结果属于回归验证。合并后 848 条预测的中位数及分桶与保留结果逐条一致；新提取代码已从原始 trace 重建上下文，无旧实验依赖。

|---|---:|---:|

| 分桶准确率 | 71.25% | 73.85% |

相对原始 Lattice，仍存在个别回归，具体修复和新增严重误差列于 `results.json`。修正依赖训练数据中的条件分布，不能保证换到预装依赖不同的环境后仍不恶化。深层依赖失败和条件执行没有全部解决。原来最坏 40 条中的环境失败，本次失败规则使 9 条退出十倍严重误差范围。
