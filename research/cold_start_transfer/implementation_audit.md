## Minimal research interfaces

`prepare.py` uses existing v5 ingestion and v6 SDK conversion. V6 compact summaries omit structural fields in older runs; the matching embedded `trace_event.artifact.calls` supplies the recorded structure, with execution/call/command identity checks. Without an embedded artifact, the existing `offline.runner._safe_recorded_clause` guard can prove a literal single argv with no shell operators or expansions; only that narrowly verified case receives standalone structural flags. Other missing structures are rejected. No synthetic resource labels are needed.

`evaluate.py` adds only an isolated repository-disjoint split, task-disjoint prefix budgets, simulated event clocks, target-specific fitting, empirical baselines, median log-residual calibration and diagnostics. It calls the original `LatticeTimeKB`, `ClauseResourceKB`, and `EdgeKappaKB`. Repository removal replaces both training and query repository strings with empty strings. The subset-coverage ablation uses the existing constructor switch. Edge comparisons include fully fixed weights and source-learned weights frozen only during target feedback, distinguishing source training from local adaptation.

All methods see the same target-specific evaluation identities. Tool-level memory is audited separately and never used as clause memory. CPU is auxiliary; RSS results do not establish admission-memory performance.

`memory_labels` validates flags, supported measurement, nonnegative values and arithmetic; it does not independently prove execution membership in the measured cgroup. The research importer additionally rejects `cgroup_v2_memory_current` labels when the recorded execution cgroup lies outside the measured path. This excludes 23 tool labels and 19 clause labels in the 20260920-134712 batch. Raw values and both paths are retained in `memory_scope_quarantine.json`; the rejection does not depend on the resource value. Union measurement IDs are logical identities and must not be interpreted as cgroup paths. Production ingestion is unchanged.
