# ClawTune Python Library and Local Service

Provides prediction models, saved knowledge bases, model proxying, execution tracing, and resource collection. Install the Python package independently or run it as a local service. See [library installation](../../docs/getting-started.md#library-and-offline-use), the [technical report](../../docs/technical-report.md) for methods, and the [installation guide](../../docs/getting-started.md) for live collection and OpenClaw integration.

Public payloads are defined in [contracts](../../contracts/). The running service's `/openapi.json` describes HTTP routes.
