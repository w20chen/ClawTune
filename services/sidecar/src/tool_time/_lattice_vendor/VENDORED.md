# Vendored lattice core

These modules are copied from `C:\\Users\\user\\Desktop\\latt`, package
`cmdtime-predictor` version `0.1.0`. Imports were changed only to use the
`tool_time._lattice_vendor` namespace.

Included modules implement command normalization, context-node generation,
node statistics, Bayesian shrinkage, LOSO reliable-specificity selection, and
risk-aware frontier selection. Dataset loading, CLI, model orchestration, and
persistence were intentionally not copied; ClawTune supplies clause telemetry,
JSON persistence, and the public protocol.
